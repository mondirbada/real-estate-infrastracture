# Real Estate Infrastructure

Progetto AWS di gruppo per l'esame di Servizi Cloud (ITS ICT Torino): piattaforma immobiliare serverless nella regione
`eu-south-1` (Milano).

La documentazione da studiare è in **[`definitivo/`](definitivo/README.md)**: un file per ogni servizio, con ruoli,
policy, trust relationship, resource policy e configurazioni, più il diagramma.

I documenti delle versioni precedenti sono in [`archivio/`](archivio/README.md).
