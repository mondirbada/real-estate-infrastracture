# Archivio

Documenti delle versioni precedenti del progetto, conservati per la storia. **La versione valida è
[`../definitivo/`](../definitivo/README.md)**: dove questi file la contraddicono, vale `definitivo/`.

- `architecture.md`, `problems.md`: il piano e le domande del team, aggiornati al 19/10/2026.
- `am-management/`: le spiegazioni IAM per componente (i JSON sono stati spostati in `definitivo/iam/`).
- `config/README.md`: la spiegazione delle configurazioni (i JSON sono in `definitivo/config/`).
- `studio/`: revisione del piano, guide di studio sui servizi e su IAM, review approfondita.
- `diagrams/`: lo schema di Tommaso (`updated.drawio` con PNG e SVG esportati, più il backup automatico di draw.io).
  Il diagramma attuale è `definitivo/diagrammi/real-estate-v2.drawio`.

I link interni di questi file possono essere rotti dallo spostamento.
